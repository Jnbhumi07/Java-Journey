# 📝 Important Notes

## What is a Variable?

A variable is a named memory location used to store data.

Example:

int age = 20;

Here,
- int → Data Type
- age → Variable Name
- = → Assignment Operator
- 20 → Value

---

## What is a Data Type?

A data type tells Java what kind of data a variable can store.

---

## Primitive Data Types

### int
Stores whole numbers.

Example:

int age = 20;

---

### double
Stores decimal numbers.

Example:

double cgpa = 8.9;

---

### char
Stores a single character.

Example:

char grade = 'A';

Use single quotes (' ').

---

### boolean
Stores true or false values.

Example:

boolean placed = false;

---

## Non-Primitive Data Type

### String

Stores text or multiple characters.

Example:

String name = "Bhumi";

Use double quotes (" ").

⚠️ String starts with a capital S because Java is case-sensitive.

---

## Identifiers

Identifiers are the names given to variables, classes, and methods.

Example:

String name = "Bhumi";

'name' is an identifier.

Rules:
- Can start with a letter, _ or $
- Cannot start with a number
- Cannot contain spaces
- Cannot use Java keywords

---

## Keywords

Keywords are reserved words in Java with predefined meanings.

Examples:

- int
- double
- public
- class
- static
- void
- new
- return

---

## Comments

Single-line comment:

// This is a comment

Multi-line comment:

/*
This is
a multi-line comment.
*/

Comments improve code readability.

---

## Printing Variables

Example:

System.out.println(name);

Output:

Bhumi

# 📝 Important Notes

## What is Java?

Java is a high-level, object-oriented programming language used to build desktop, web, mobile, and enterprise applications.

---

## JDK

Java Development Kit

Purpose:
Used to develop Java programs.

Contains:
- JRE
- Compiler (javac)
- Development Tools

---

## JRE

Java Runtime Environment

Purpose:
Used to run Java programs.

Contains:
- JVM
- Libraries

---

## JVM

Java Virtual Machine

Purpose:
Executes Java bytecode (.class file).

---

## Java Program Flow

.java File
      ↓
javac (Compiler)
      ↓
.class File
      ↓
JVM
      ↓
Output

---

## main() Method

public static void main(String[] args)

It is the entry point of every Java program.

Execution starts from the main() method.

---

## System.out.println()

Used to print output on the screen.

Example:

System.out.println("Hello Bhumi");

---

## Semicolon (;)

Ends a Java statement.

---

## Case Sensitive

Java is case-sensitive.

Correct:
String

Wrong:
string

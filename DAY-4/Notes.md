# 📝 Important Notes

## What is an Operator?

An operator is a symbol that performs an operation on operands (values or variables).

Example:

10 + 5

Here:
- 10 → Operand
- 5 → Operand
- + → Operator

---

## What is an Operand?

An operand is the value or variable on which an operation is performed.

Example:

10 + 5

10 and 5 are operands.

---

# Arithmetic Operators

Used to perform mathematical calculations.

| Operator | Meaning |
|----------|---------|
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| % | Modulus (Remainder) |

Example:

int a = 20;
int b = 5;

System.out.println(a + b);

---

# Assignment Operators

Used to assign or update values.

| Operator | Example | Meaning |
|----------|---------|---------|
| = | a = 10 | Assign Value |
| += | a += 5 | a = a + 5 |
| -= | a -= 5 | a = a - 5 |
| *= | a *= 5 | a = a * 5 |
| /= | a /= 5 | a = a / 5 |
| %= | a %= 5 | a = a % 5 |

---

# Relational Operators

Used to compare two values.

| Operator | Meaning |
|----------|---------|
| == | Equal To |
| != | Not Equal To |
| > | Greater Than |
| < | Less Than |
| >= | Greater Than or Equal To |
| <= | Less Than or Equal To |

Output of Relational Operators is always:

- true
- false

Example:

20 > 10

Output:

true

---

# Logical Operators

Used to combine two or more conditions.

| Operator | Meaning |
|----------|---------|
| && | AND |
| || | OR |
| ! | NOT |

Examples:

True && True → True

True && False → False

False || True → True

!True → False

!False → True
